# WEGOTCHU: Data Flow & Interface Contracts (v0.1)

## 1. Specification Overview

This document specifies the communication interfaces, telemetry contracts, and schema definitions across the WEGOTCHU architecture. 

All contracts documented here are labeled **Version 0.1 (Draft Prototype)**. They are designed to evolve with semantic versioning as edge models and backend microservices mature.

---

## 2. End-to-End Data Pipeline Flow

```mermaid
sequenceDiagram
    autonumber
    participant Mobile as Mobile Client (Android)
    participant Edge as Edge Inference (ONNX/LiteRT)
    participant Backend as Backend API (FastAPI)
    participant AI as AI Risk Engine
    participant Policy as Safety Policy Engine
    participant GenAI as GenAI Gateway
    participant Contacts as Trusted Contacts

    Mobile->>Mobile: Sample IMU (50Hz), GPS (1Hz), Audio (16kHz)
    Mobile->>Edge: Stream ephemeral sensor frames
    Edge->>Edge: Compute Kinematic & Acoustic Features
    
    alt Standalone Edge Mode (Low Network)
        Edge->>Edge: Local Baseline & Anomaly Inference
        Edge->>Policy: Evaluate Local Policy
    else Connected Mode
        Edge->>Backend: Post Telemetry & Feature Vector
        Backend->>AI: Forward Extracted Features
        AI->>AI: Temporal Modeling + Multimodal Fusion
        AI->>Backend: Output Structured Risk Evaluation
        Backend->>Policy: Evaluate Risk State Machine
    end

    opt Risk State >= ELEVATED
        Policy->>Mobile: Trigger Discreet Haptic User Check-in
    end

    opt Check-in Unacknowledged / State == HIGH or EMERGENCY
        Policy->>GenAI: Request Contextual Alert Briefing
        GenAI->>Policy: Return Structured Briefing Text
        Policy->>Backend: Dispatch Emergency Payload
        Backend->>Contacts: Deliver SMS / Push / Live Web Link
    end
```

### Contract 5: GenAI Emergency Briefing Request & Response
*Contract between Policy Engine and GenAI Communication Service.*

#### Request (To GenAI Service):
```json
{
  "user_first_name": "Alex",
  "risk_level": "HIGH",
  "confirmed_signals": ["route_deviation", "acoustic_distress"],
  "last_known_location": {
    "address_hint": "Near 4th & Market St",
    "latitude": 37.7858,
    "longitude": -122.4065,
    "maps_url": "https://maps.wegotchu.app/loc/x881f"
  },
  "elapsed_checkin_seconds": 45,
  "battery_percentage": 42
}
```
